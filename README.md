# FNF Mod Manager

تطبيق أندرويد (Kotlin + Jetpack Compose) محلي بالكامل: تختار مود V-Slice موجود على هاتفك (ZIP أو مجلد)، وتختار مجلد اللعبة بنفسك وتكتب إصدارها، فيثبّته التطبيق في `mods`.
لا يوجد تحميل أو كتالوج أونلاين.

- لا استبدال صامت: عند وجود مود بنفس الاسم يُعرض تثبيت كنسخة جديدة أو استبدال مع نسخة احتياطية.
- سجل تثبيت خاص بالتطبيق؛ الإزالة تحذف الملفات المسجلة فقط، وفحص المود يقارنها بالسجل.
- التصميم: `design/` (المرجع + SVG)، الأيقونات تتحوّل بـ `scripts/build_assets.py`. الخط IBM Plex Sans Arabic يُحمَّل في الـ workflow.
- الـ APK يظهر في Releases بعد كل Push على main.
