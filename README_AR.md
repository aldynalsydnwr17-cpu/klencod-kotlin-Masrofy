# FNF Mod Manager — Android

مشروع Android Studio (Kotlin + Jetpack Compose) بواجهة عربية RTL وألوان مستوحاة من التصميم المرفق.

## فتح المشروع
1. فك ملف ZIP.
2. افتح مجلد `FNFModManager` في Android Studio.
3. انتظر Gradle Sync ثم شغّل التطبيق على هاتف Android أو Emulator.

## الوظائف المتوفرة
- اختيار مجلد اللعبة من خلال Android Storage Access Framework وحفظ صلاحية الوصول.
- حفظ إصدار اللعبة الذي يكتبه المستخدم.
- اختيار ZIP واستيراد محتوياته إلى `Mods/<اسم المود>` مع منع مسارات ZIP غير الآمنة (`../`).
- مكتبة محلية تحفظ أسماء المودات وإصداراتها.
- تفاصيل المود وإزالته من مجلد Mods.
- تصميم عربي RTL وصفحات الرئيسية/المكتبة/الاستيراد/الإعدادات.

## ملاحظات واقعية
- Android لا يسمح للتطبيق باكتشاف مسار لعبة آخر تلقائيًا؛ المستخدم يمنح إذن المجلد عبر منتقي النظام.
- دعم التشغيل المباشر يعتمد على package name الخاص بنسخة FNF المثبتة. الكود يحاول package الرسمي الشائع؛ يمكن ضبطه في `launchGame`.
- ZIP هو مسار الاستيراد المنفذ حاليًا. استيراد مجلد مود مباشر، معاينة أغلفة فعلية من metadata، وإدارة توافق كل fork من FNF تحتاج اختبارًا على إصدار اللعبة ومجلد Mods الفعلي.
- الصور المرجعية والشخصيات الرسمية ليست مضمنة؛ أغلفة الكروت رسومية مؤقتة بالكود حتى يختار المستخدم غلافًا خاصًا.

## بناء APK من GitHub
1. أنشئ Repository جديدًا على GitHub.
2. ارفع محتويات هذا المجلد إلى جذر المستودع (لا ترفع المجلد الخارجي نفسه).
3. افتح تبويب **Actions** واسمح بتشغيل GitHub Actions إذا طلب ذلك.
4. بعد Push إلى `main` أو `master`، افتح Workflow باسم **Build Android APK**.
5. نزّل Artifact باسم `FNF-Mod-Manager-debug-apk`؛ بداخله APK تجريبي للتثبيت.

هذا workflow يبني Debug APK وليس نسخة Release موقعة للنشر.
